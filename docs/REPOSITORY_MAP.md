# Organization map

This MVP follows the repository plan:

- `docs/` — proposal and operations documents
- `agents/` — role specifications
- `clients/_TEMPLATE/` — private-safe client template
- `schemas/` — machine-readable client schema
- `config/agency.yaml` — schedule and status configuration
- `src/` — application workflow and state machine
- `public/` — owner approval console
- `tests/` — automated safety tests
